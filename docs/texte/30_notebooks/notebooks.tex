\section{Live Demo}\index{live demo}

The page \texttt{demo/interferometer\_demo.html} is a live demonstration of
a two-element interferometer for talks and screen recordings. It is a
single self-contained file (HTML, canvas and JavaScript, no libraries)
and runs in any browser without Python; the user interface is German by
default and can be switched to English.

Sliders set the frequency, flux density, direction and distance of the
source (spherical or plane wave), source size, baseline, dish diameter,
pointing, bandwidth (length of the wave train), system temperature,
integration time, instrumental delay, slow motion and Earth rotation.
Six panels show the wavefronts, the received signals of both antennas
(in the same absolute time as the wavefronts), the correlator with the
complex visibility, the fringe pattern over the direction, the fringes
over time and the sensitivity. Seven guided steps lead through a
demonstration. The delay compensation acts on the envelope after mixing,
as in a real receiver; the formulas are those of the package.
